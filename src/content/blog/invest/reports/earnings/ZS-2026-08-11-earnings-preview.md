# Earnings Preview - ZS - 2026-08-11

## 1. Company Context

Zscaler 是云原生零信任安全平台领导者。核心产品 Zscaler Internet Access (ZIA) 和 Zscaler Private Access (ZPA) 构成了"不信任任何人、验证所有连接"的安全架构。

**Theme:** Cybersecurity

**为什么重要：** Cyber 是我持仓的第二大板块（PANW + ZS = 15.3%）。ZS 代表"纯云安全"路线（vs PANW 的平台化路线）。零信任是 AI 时代安全架构的基础——越多 AI Agent 自主运行，越需要"每次访问都验证"的架构。

2026 Gartner Magic Quadrant SASE 和 Security Service Edge 双料领导者。

## 2. Current Investment Thesis

- **为什么持有？** 零信任安全是长期结构性趋势，ZS 是纯云架构的龙头
- **长期驱动力：** 企业 VPN → 零信任迁移。AI Agent / agentic AI 扩大零信任 TAM
- **近期催化：** Q4 FY2026 财报（Sep 2-3）。前三个季度连续 beat，如果 Q4 延续 + FY27 指引上调 → 信任修复
- **Thesis 变化：** 偏弱但在改善。FY26 初指引下调导致暴跌 -31%（May 2026），但后续三个季度连续 beat。市场对管理层指引保守性的信任在缓慢重建。Gartner SASE 领导者认证 + AI 安全新品（AI-Guardian）是正向信号

## 9. Stock Strategy Framework

**当前状态：** 40 股 @ $202.64，浮亏 -13%，仓位 4.9%（Starter+）

**可选方案：**

1. **财报前不动，财报后根据反应决定**（推荐）
   - 仓位 4.9% 可控，即使 gap down -15% 只影响组合 ~0.7%
   - 避免在 FY27 指引不确定时加大敞口

2. **财报前小幅加仓（如破 $180-185 前高 + 浮亏收窄至 -10%）**
   - 符合你设定的条件：破前高站稳 + 浮亏 <10%
   - 风险：财报 gap down 后浮亏加大

3. **财报后 bull case 兑现再加仓**
   - 最安全的路径。如果 FY27 指引 >20% + beat，趋势确认后加到 Half/Full
   - 代价：追高几个点，但有信息优势

**注意：** 浮亏 >10% 冻结加仓规则 仍然生效。当前 -13%。需要 ZS 涨到 ~$182+ 才能到 -10% 以内。这个价位恰好也是前期高点突破区间，两个条件可能同时满足。

## 10. Options Strategy Framework

### Long Call
- 适用场景：强看好 FY27 指引上调 + beat
- 主要风险：Theta 衰减 + 如果指引失望 Call 归零
- 当前不推荐：方向判断信心 Medium，不值得付高 IV 溢价

### Long Put
- 适用场景：对冲持仓的财报下行风险
- 可考虑：买 $160 Put 保护（如果 IV 不太贵）
- 4.9% 仓位是否值得付保费？成本效益不高

### Long Straddle / Strangle
- 适用场景：认为实际波动 > 隐含波动
- ZS 历史财报波动大（-31% 到 +15%），straddle 可能有利
- 但需要看 IV 水平，missing data

**提醒：** 期权是杠杆，最大亏损 = 权利金。按规则期权敞口不超过 5%。
